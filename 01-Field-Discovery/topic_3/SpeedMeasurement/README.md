# SpeedMeasurement · 局域网测速站

Rust（axum）写的本地测速服务。电脑开热点、手机连上后打开网页，测延迟 / 抖动 / 下载 / 上传，
并把不同位置（隔不同墙体材质）的结果记录下来做对比。全程只在局域网内，不依赖外网。

## 运行

```bash
cargo run --release
# 或直接跑已构建的二进制
./target/release/SpeedMeasurement
```

默认监听 `0.0.0.0:8080`，可用 `PORT=9000` 覆盖。

启动后会打印手机可用的地址，例如：

```
手机访问（与电脑同一热点/局域网）：
  http://192.168.137.1:8080
```

### 手机连接

1. 电脑开启热点（或手机与电脑连同一个 WiFi）
2. 手机浏览器打开启动日志里的地址
3. 点「开始测试」

> 若手机打不开：检查电脑防火墙是否放行 8080/TCP（Windows 首次运行会弹窗询问，选允许）。
> 电脑有多个网卡时启动日志会列出全部地址，逐个试即可。

## 测速口径

| 项目 | 方法 |
|------|------|
| 延迟 | 16 次 `GET /api/ping`，丢弃前 3 次，取中位数 |
| 抖动 | 上述样本的标准差 |
| 下载 | 4 并发流式读取，8 秒窗口内的平均速率 |
| 上传 | 4 并发 POST 4 MiB，8 秒窗口内的平均速率 |

速度单位 Mbps（bits/s ÷ 10⁶）。

## 墙体 / 多径对比方法

把手机依次放到不同位置：同一房间、隔一堵混凝土墙、隔木门、隔玻璃……每个位置测 3 次，
保存时标注位置与墙体材质。历史列表里的百分比条形 = 下载速率相对最快一次的保留率；
结合 Ping 与抖动，就能看出穿墙衰减和多径对速率 / 时延的影响。

## 数据

结果存于 `data/results.json`，删除该文件即可重置。

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/` | 页面 |
| GET | `/api/info` | 本机局域网地址列表 |
| GET | `/api/ping` | 204，用于 RTT |
| GET | `/api/download?bytes=N` | 流式输出 N 字节 |
| POST | `/api/upload` | 流式接收并统计字节数 |
| GET/POST | `/api/results` | 列出 / 保存结果 |
| DELETE | `/api/results/{id}` | 删除一条结果 |
