### 1.2 阈值规则（4 类，4 s 窗 / 0.5 s 步长）

| 顺序 | 条件 | 判定 |
|---|---|---|
| 1 | `σ(\|a\|) < 0.30 m/s²` | 静止 |
| 2 | `σ(\|a\|) > 8.0 m/s²` 或峰值 `\|a\| > 40 m/s²` | 快跑 |
| 3 | `σ_v / σ_h > 1.50` | 上下楼梯 |
| 4 | 其余 | 平地慢走 |

顺序不能交换：快跑的 `σ_v/σ_h` 中位也有 1.67，会越过第 3 条，必须先用 σ / 峰值把快跑判走。4 份提交记录的 σ 中位为静止 0.05、慢走 2.08、楼梯 4.48、快跑 15.83 m/s²，三条阈值两侧的最近余量约 1.8 倍。4 类口径的跨日：把 v6 的 `up` / `down` 合并（`output/v6/windows.csv`），10-25 为 **95.45 %**（672/704），v5.1 为 96.02 %（676/704）。

## 3 方法

```
Accelerometer + Gravity
  → 重力插值 / 逐样本解耦（a_v, a_h）
  → 首尾清洗（掉零、启停瞬态、0.5 s 保护带）
  → 8 s 窗 / 1 s 步长（4 类交付为 4 s / 0.5 s）
  → 窗特征 → 分位标定 → 分层规则 → 段级解码
```

| 特征 | 对零偏 `s→s+c` | 对增益 `s→a·s` | 用途 |
|---|---|---|---|
| `rob_skew = (q95+q05−2q50)/(q95−q05)` | 不变 | 不变 | 判下楼 |
| `acp` / `zcr` | 不变 | 不变 | 慢走 / 上楼打分 |
| `sigma = std(\|a−g\|)` | 会变 | 随增益线性变 | 只做静止 / 快跑门限 |

![v2 图 2](output/v2/figures/fig2_decompose.png)

## 7 局限与结论

1. **一人一机**：全部数据来自本人、同一台 PKG110；跨设备、跨人未验证。
2. **4 类 97.5 % 是同集标定结果**，只能当拟合度；真正有泛化意义的是 5 类跨日。
3. **2026-10-25 曾用于 v5.1 / v6 方向选择**；2026-11-17 完全未参与任何版本选择。
4. **不摆臂是协议外变量**，引用跨日数字时只用标准段。
5. **跨日窗口级 86.8–94.6 %**，记录级全对；失分集中在上楼 / 下楼 / 慢走互混。
6. **v7 训练集是一人一机三天**，换手机或换人必须重训、重验。
7. **窗重叠 7/8**：704 个 8 s 窗去重叠后只剩 90 个；4 类交付里 run 只有 15.6 s（21 窗，约 3 个独立 4 s 窗），引用时以记录级为主。
8. **照片证据只覆盖 `data_1`、`data_2`**；后续跨日数据只有 `meta/` 可回查。
9. **4 份 CSV 的导出流不同**：01/02 为 201.6 Hz 去重力线性加速度，03/04 为 403.1 Hz 含重力；v1 的 σ 不受常量偏置影响，但 `σ_v/σ_h` 在 01/02 上由窗均值方向估计，不是真实重力（v2 起改用 Gravity 传感器解耦）。03 只含下楼梯样本，上楼样本在 `data_1` 的 `go_upstairs-*`（169 窗，v1 全部判对）。

**结论**：课题要求的 4 类已完整交付并可复现——4 份原始 CSV、8 张图、4 条顺序阈值，窗口级 346/355 = 97.5 %，记录级 4/4。扩展分析表明：5 类同集可到 98 %，跨日窗口级 86.8–94.6 %、记录级全对；跨日失效的根源是 `ptn` 一类非平移不变量的零偏漂移，换成 `rob_skew` 后回到 94 %。不摆臂场景由固定门限造成：训练集不摆臂段 v6 27.6 %、外部 11-17 37.1 %，v7 折外 94.0 %、外部 94.5 %。
