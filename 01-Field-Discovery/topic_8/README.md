# 课题 8 实验报告：多姿态步态加速度判别（v1 → v7）

> **任务**：只用一个手机加速度传感器，把「静止 / 平地慢走 / 快跑 / 上楼 / 下楼」从加速度波形里判出来。
> **采集**：本人。OnePlus Ace 5（`PKG110`，Android 16），Phyphox 1.2.1；加速度约 403 Hz，Gravity 约 201.6 Hz。
> **数据**：5 组 72 段，全部本人采集，无他人 / 他机数据。61 段 / 4431 个 8 s 窗参与评估；另 11 段早期数据用于 v1 的 4 类验证。
> **交付**：课题要求的 4 份原始 CSV（[`output/v1/csv/`](output/v1/csv/)）+ 全部代码（[`src/`](src/)）+ 逐窗结果（[`output/`](output/)）+ 本文。
> **版本**：v7.0（2026-11-01）。规则主线 v6；监督学习分支 v7。

## 摘要

课题原始要求是 4 类：平地慢走、快跑、上下楼梯、静止。本报告先按 4 类交付原始数据：4 段、355 个 4 s 窗，判对 346 个（97.5 %）；再把「上下楼梯」拆成上楼、下楼，用同一个 8 s 窗做 5 类分析。

难点不在同一天。v2 / v4 / v5 在本人同批数据上做到 97–99 %，换一天（同一台 PKG110）只剩 42.8–79.7 %（v5 最好，79.7 %）。原因不是特征不够多，而是判下楼的 `ptn = (峰−谷)/(峰+谷)` 会随窗内残余零偏平移，跨日漂移的正是零偏；换成对零偏与增益都不变的稳健偏度 `rob_skew` 后，同一个分位标定就把跨日拉回 **94.6 %（v5.1）/ 94.5 %（v6）**，记录级 9/9。

三天后补采的 23 段标准段（1662 窗）给出第二组跨日复核：v5.1 93.3 %、v6 92.7 %，与 94.6 / 94.5 的置信区间重叠，记录级 23/23。同一批 13 段「不摆臂」采集把 v6 打到 27.6 %：失效点是固定门限 `stand = 1.100` 与 `rob_skew` 的切分，不是特征缺失。用这 36 段训练的 RBF-SVM（v7）在段级分组折外 94.2 %、留一天 94.0 %；把模型用到 2026-10-25 上，窗口级 92.8 %、记录级 9/9，比 v6 低 1.7 个点——学习模型买的是换持机方式的鲁棒性，不是无条件的准确率。

三个边界先说清楚：**一人一机**（PKG110，两组跨日数据仍同一人同一手机）；**「不摆臂」是协议外变量**，引用跨日数字时只用标准段；**2026-10-25 曾用于 v5.1/v6 选型**，对 v7 也只能算外部抽样复核，不是完全未看过。

### 3.2 逐样本重力解耦

手机握在手里摆臂时，「窗口内三轴均值方向 = 重力方向」这个假设不成立（§5.2）。本报告用 Phyphox 同时导出的 `Gravity` 传感器逐样本解耦。设 `g(t)` 为重力读数，`ĝ = g/|g|`：

```
a_v = a·ĝ − |g|                    竖向动态加速度（扣掉 9.8 常量）
d   = a − g                        动态加速度向量
a_h = |d − (d·ĝ)ĝ|                 横向动态幅值（= √(|d|² − a_v²)）
```

静止时 `d ≈ 0`，运动时 `|d|` 就是不含重力的动态加速度。

### 3.3 特征：先分不变性，再谈判别力

这是全报告的方法论主线：**先问一个量在「换一天」时会不会变，再问它判别力强不强。**

| 类别 | 特征 | 对零偏 `s→s+c` | 对增益 `s→a·s` | 用途 |
|---|---|---|---|---|
| **不变核** | `rob_skew = (q95 + q05 − 2·q50) / (q95 − q05)` | 不变 | 不变 | 判下楼 |
| | `acp`：0.30–1.20 s 内窗自相关峰 | 不变 | 不变 | 慢走 / 上楼打分 |
| | `zcr`：过零率 | 不变 | 不变 | 慢走 / 上楼打分 |
| 协变量 | `rob_skew` 在 `s→−s` 下变号 | — | — | 符号即上 / 下楼的物理差别 |
| **非不变** | `sigma = std(\|a−g\|)` | — | 随增益线性变 | 只做静止 / 快跑两个门限 |
| 诊断量 | `cadence`、`i_cv`、`ac_lag`、`bias` | — | — | 只输出，不进判决 |

为什么较真：v5 判下楼的 `ptn = (mean(pv) − mean(tv)) / (mean(pv) + mean(tv))` 看起来是「比值」，但分子分母都含 `pv + tv`。给窗内所有样本加常数 `c` 时，峰抬 `c`、谷的绝对值降 `c`，`ptn` 随之改变——它**不是平移不变**的。窗内减中位数只能压掉当天的 `c`；估偏或 `c` 随手持变，判决就漂。跨日漂的正是这个量。`rob_skew` 加 `c` 时三个分位各加 `c`，分子分母同时不变；乘 `a` 时分子分母同乘 `a`。**加性零偏与增益都进不了判决。**

早期版本的绝对幅值特征（v2/v3 的 `σ`、`p99`、`σ_v`、`f_dom`、`r`）在同集上判别力很强，但换一天整体偏移就失效（§4.1、§5.2），是「先看判别力、后看不变性」的代价。

### 3.4 判决：分位标定 → 分层规则 → 段级解码

1. **分位标定**：所有阈值取两个类 2 % / 98 % 分位之间的中点，不用 `max/min`——单个异常窗就能把极值阈值拖走。有符号量（`rob_skew`）用算术中点；绝对值量（`sigma`）用几何中点。
2. **分层规则**（顺序与 v4 一致）：`sigma` 低于静止门限 → 静止；高于快跑门限 → 快跑；`rob_skew` 高于下楼门限 → 下楼；`−z(acp) − z(zcr)` 高于门限 → 上楼；否则慢走。权重固定为 1，不在测试集上调。
3. **段级解码**：逐窗判决是「观测」，解码在状态图（`walk` 在中心，其余四类只在走路时进出）上最小化 `Σ 观测代价（判对 0 / 判错 1） + Σ 切换代价（penalty × 图上距离）`。`penalty` 只在留一上选（v6 得 1.0），离线整段解码；因果模式（只看过去窗）也实现了（§4.8）。

**最终判决参数**（`data_2 + 2026-10-24` 标定，2 % / 98 % 分位；完整报告见 [`output/v6/report.txt`](output/v6/report.txt)）：

| 判决 | 特征 | 阈值 |
|---|---|---|
| 静止 | `sigma` | 1.100 |
| 快跑 | `sigma` | 4.121 |
| 下楼 | `rob_skew` | +0.1108 |
| 上楼 | `−z(acp) − z(zcr)` | +0.633 |
| 其余 | — | 平地慢走 |
| 段级解码 | Viterbi | penalty = 1.0（只在留一上选） |

`sigma` 是唯一保留的绝对幅值量，只用于静止 / 快跑两个门限；`rob_skew` 与 `acp` / `zcr` 对零偏、增益不变（§3.3）；up score 的 z 归一化参数在标定集上固定，权重为 1。

### 3.5 窗长与步长

**8 s 窗 / 1 s 步长**。4 s 在 1.7 Hz 步频下只有约 7 步，`σ_v` / `σ_h` 的估计方差大。同一套 v2 流程在 `data_2` 上：4 s 91.8 %、6 s 94.9 %、8 s 97.4 %、10 s 99.7 %（10 s 时 `run-1` 不足一个窗被整体丢掉，只剩 6 段 288 窗，与前三档不可比，故取 8 s）。

「加长窗就涨」在跨日上会反过来咬人：16 s 窗在跨日盲测上能到 99.7 %，但留一掉到 84.3 %——`data_2/run-1` 只有 11.9 s，长窗下快跑整类消失（§6）。

### 3.6 四种评价协议

| 协议 | 做法 | 读法 |
|---|---|---|
| 同集 | 标定集自身 | 只当拟合度，不能当泛化 |
| 留一记录 | 16 段轮留，每折重标定全部阈值 | 最严格的**同人同机**协议 |
| 盲测 | 标定集固定，测试集不参与任何选择 | 跨日两组（同人同机） |
| 因果 | 只允许看过去窗 | 接近在线；结果见 §4.8 |

另外三种口径用于读区间：**Wilson 95 %**（把窗当独立样本，偏窄）、**记录级 bootstrap**（按段重采样 B=2000，偏保守）、**去重叠**（每段每 8 窗取 1 窗，704 → 90）。8 s 窗 / 1 s 步长使相邻窗重叠 7/8，点准确率不能按独立样本数读，引用时以记录级为主。

v7 与 v6 并列，不互相替代：v6 零训练、可解释、可审计，是零重训基线；v7 依赖 36 段训练数据与一个模型文件，换手机或换人必须重训。复现见 §7.3。

### 4.8 因果与在线

跨日盲测上，只允许看过去窗时 v6 是 **93.32 %**（离线 94.46 %），v5.1 的尾随 5 窗多数票是 93.75 %。也就是说**段级解码的收益目前只出现在离线 / 整段场景，在线反而略低**；要上线应当用 causal Viterbi 或加大切换代价再验一次，不能直接套离线数字。

### 5.2 四个关键节点

**v1：重力假设失效。** v1 把「窗口内三轴均值方向」当作重力方向。手机拿在手里摆臂时该假设不成立：`stand` 的 `|mean(a)|` 是 9.78 m/s²，而 `walk-1` 是 11.97、`go_upstairs` 10.84、`go_downstairs` 11.05、`run-2` 24.76——只有静止段落在 9.807 上。于是 `r` 对慢走是 2.43–2.51、对上楼是 2.40，完全缠在一起；改用真实重力后顺序恢复正常（慢走 1.23–1.34、上楼 1.05、下楼 1.99）。四条阈值原样搬到 `data_2` 只有 39.7 %，179/180 个慢走窗被判成楼梯。

**v4：从窗统计量转向波形。** 0.08 s 低通后检测峰 / 谷（局部极大 + 全窗最大值 ×0.3 高度门限 + 0.30 s 最小间距），用峰谷比 `pt` 判下楼、窗内自相关峰 `acp` 判慢走 / 上楼，后接 ±2 窗多数票。这是第一次用相对量把跨日从 45.3 % 拉到 68.6 %；但 `pt` 是极值之比，不是不变量的比值，埋下了 v5 的坑。

**v5.1：只换一个判决量。** `ptn` 的分子分母都含 `pv + tv`，加常数 `c` 时峰抬 `c`、谷的绝对值降 `c`，`ptn` 随之改变。换成 5 % / 95 % 分位的 `rob_skew` 后，加 `c` 时三个分位各加 `c`、分子分母同时不变，乘 `a` 时同乘 `a`。同一条流水线只改这一处，跨日 79.7 % → 94.6 %，被下楼误吞的窗从 122 个降到 14 个。代价明确记下：只用 10-24 标定、测 `data_2` 的那一折，v5.1 比 v5 低 2 个点（94.4 vs 96.4），因为 `rob_skew` 在两组之间也有约 0.07 的数据级偏移（`ptn` 只有 0.03），只是它离下楼的间隔更大；两个方向的平均 v5 95.6 % / v5.1 94.6 %。

阈值估计器也一并修了一处：有符号量上继续用 v4 的几何中点会被 0 附近的 q98 拉到多数类一侧（只拿 10-24 标定、测 `data_2` 时，walk/up q98 只有 +0.001，几何中点给出 0.013 的阈值，而 `data_2` 慢走上尾是 0.062，准确率只有 83.4 %）；改成 2 % / 98 % 分位间隔的**算术中点**后 94.4 %。v5 的 `ptn` 仍用几何中点，历史数字保持可复现。

**v6：把不变性写成自检。** 四层：`src/v6/invariants.py` 对 `s→s+c`、`s→a·s`、`s→a·s+c` 逐特征断言不变（RTOL 1e-9），对 `s→−s` 断言 `rob_skew` 变号，对 `std` 断言「它确实会变」；`features.py` 把不变核 / 诊断量 / 非不变量显式分列；`model.py` 做分位标定 + 分层规则 + Viterbi；`evaluate.py` 一次跑完同集 / 留一 / 跨日 / 因果 / 去重叠 / bootstrap。这个自检不是形式主义：**如果它早存在，v5 的 `ptn` 在写下的当天就会被判不合格，79.7 % 这个数字根本不会出现。**

v6 同时用段级解码把留一推到 95.86 %（`penalty = 1.0`，只在留一上选）。它没有做三件事，也是结论：不把 `sigma` 换成不变量（试过 `acp`、谱熵、8–20 Hz 能量占比、峰度，静止与运动的间隔都会从「0.06 vs 2.0 m/s²」掉到 0.37 vs 0.43 这种不可用的重叠区）；不加长窗（16 s 窗留一掉到 84.3 %）；不做会话级归一化（单段记录只有一种状态，减段内中位数会把唯一的状态也减掉）。

### 5.3 外部评审逐条核查

v4 之后有一份外部评审，核心意见是：峰谷检测升级（prominence / 最小高度 / 最小宽度 / `scipy.signal.find_peaks`）、加周期性质量指标、对 `pt` 归一化、把硬阈值链改成打分制、加步频约束、阈值标定用留一 / 分位数、盲测前做零偏 / 佩戴对齐。逐条核查如下——能用的进 v5，不能用的给反例。

| # | 意见 | 结论 | 证据与处理 |
|---|---|---|---|
| 1 | 峰谷检测升级到 prominence / 高度 / 宽度 | 方向对，不是瓶颈 | 自实现 prominence（k = 1.0–4.0）替换后 n_steps 中位 15（v4 是 13），`ptn` 与 v4 版相关仅 0.78–0.80；留一 95.6 % → 87.5–90.0 %。残余错误在 up/walk 边界与记录首尾，不是漏检峰。**不替换。** |
| 2 | 周期性质量指标（`ac_lag` 落 0.5–3 Hz；`i_cv` 大时降权） | 部分成立，但给出的量不判别 | `acp` 搜索范围已是 0.83–3.33 Hz，慢走主峰常落 1.1 s（≈0.9 Hz）仍在范围内，剔不掉任何窗。`i_cv` 权重 0.6 → 留一 94.8 %；`cadence` 权重 0.3 / 0.6 → 94.7 % / 95.0 %（v5 是 95.7 %）。**改用 `zcr`，`i_cv` / `cadence` 只作诊断。** |
| 3 | `pt` 归一化：`(pv−tv)/(pv+tv)` 或除以窗 σ | 方向对，「除以 σ」无益，真问题是零偏 | `(pv−tv)/(pv+tv)` 是 `pt` 的单调变换，单阈值下等价；窗内 `a_v` 中位数绝对值中位 0.36、最大 6.19，`pt` 被这个直流系统性压低。**采用「减中位数 + 归一化」，不除以 σ。** |
| 4 | 判决改打分制 | 采纳，但只用于真正重叠的 up/walk | stand/run 间隔很大（σ 0.784 vs 1.545；3.354 vs 5.064），down 的 `ptn` 也已分开，给它们打分只增加参数。**只有 up/walk 用 `−z(acp)−z(zcr)`，等权、不调参。** |
| 5 | 加步频约束（`cadence` / `ac_lag` / σ 联合） | 不采纳为主判决 | 见 #2：`cadence` 让留一降到 94.7 % / 95.0 %——8 s 窗在记录首尾只有半步，真实慢走的 `cadence` 被拉低，当「上楼」证据会制造假上楼。**只输出，不判决。** |
| 6 | 阈值标定加鲁棒性（留一、分位数 / 中位数） | 采纳 | 极值 → 2 % / 98 % 分位：stand 1.100、run 4.121、`ptn` 0.123。留一从 v4 的「只留 4 段」扩到 16 段：v4 91.93 %，v5 95.65 %。 |
| 7 | 盲测前做零偏 / 佩戴对齐 | 部分采纳：零偏；不做幅值缩放 | 零偏已采用；σ 只用于 stand/run，其余都是比值或无量纲量，跨日「快跑」38/38 说明绝对量级在门限上仍可用；重力由 Gravity 传感器逐样本给出。**但跨日盲测说明「窗内减中位数」还不够。** |

**总体判断**：评审的大方向（从硬阈值转向波形 + 形态 + 周期 + 后处理）与 v4 一致，但「核心瓶颈在峰谷检测鲁棒性」不成立；真正有效的三条按贡献排序是**零偏 / 归一化 > 分位标定 > up/walk 打分**，其余未通过留一验证。

## 6 讨论与局限

1. **一人一机。** 全部 72 段来自本人、同一台 PKG110；两组跨日数据也没有换人或换机。跨设备、跨人的泛化未验证。
2. **2026-10-25 不是完全没看过。** 它在 v5 定稿后才进仓库，但 v5.1 / v6 的「不变性」方向是在看到它之后确认的，只能当回归集回看；第二组复核（10-30～11-01）补上了这一点，但仍是同一人同一机。
3. **候选类重叠是 5 类的真瓶颈。** 慢走夹在上楼与下楼之间；2026-10-25 的 39 个错窗里有 28 个是慢走↔上楼（v5.1 是 24/38）。靠加单窗特征换不来，要么补更多天 / 更多场景，要么把输出单位从「窗口」改成「段」（记录级已 9/9）。
4. **「不摆臂」是协议外变量，不是跨日变量。** 13 段不摆臂采集同时改变了日期与摆臂方式：v5.1 / v6 只有 27.9 % / 27.6 %，但特征上不摆臂上下楼可分（段级 σ / `i_cv` AUC 1.000）；失效来自 `stand = 1.100` 与 `rob_skew` 的固定切分，不是特征不足。引用跨日数字时只能用标准段。
5. **学习模型（v7）的收益与代价不对称。** 不摆臂段 27.6 % → 90–94 %，但外部 2026-10-25 比 v6 低 1.7 个点；折外 / LODO 都是训练集内部口径，训练集一人一机三天。
6. **绝对加速度值不能当人体加速度读。** 快跑峰值 111 m/s² ≈ 11.3 g，来自手机在掌中拍击 / 翻转，只作为「区分快跑」的信号特征。
7. **静止门限的验证面很窄。** 2026-10-25 有 39 个静止窗、2026-10-24 有 38 个、三天复核 110 个，`stand = 1.100` 全部判对，但都是手持采集；站立时手臂静止、不存在「摆臂」变量，若改用口袋 / 支架 / 不同握持，该门限与学习模型都未验证。
8. **窗口重叠放大样本量。** 8 s 窗 / 1 s 步长使 704 个窗去重叠后只剩 90 个；点准确率应结合 Wilson 区间、记录级 bootstrap 与去重叠一起读，不宜按独立样本数比较。
9. **在线场景需要重验。** 因果模式下 v6 93.32 %、v5.1 93.75 %，段级解码的离线收益没有带到在线。
10. **v5.1 与 v6 只差 1 个窗。** 94.60 vs 94.46。v6 的收益在留一（95.86 vs 95.54）与「以后不会再出同类错」（可执行自检），不在跨日；同集 98.9 % 反而比 v5.1 的 99.1 % 低一点。
11. **照片证据只覆盖早期数据。** `data_1`、`data_2` 有照片 / 截图；2026-10-24、2026-10-25、10-30～11-01 没有。
12. **快跑样本少且短。** `data_2/run-1` 只有 11.9 s；长窗（16 s）下快跑整类消失，留一掉到 84.3 %，这是选择 8 s 窗的原因之一。
13. **训练集内部数字不能当盲测。** 折外与 LODO 都按段分组避免同段窗泄漏，但同一人、同一手机、同一批采集环境；外部检查也只有一天。

## 附录 B：符号与术语

| 符号 | 含义 |
|---|---|
| `a`、`g`、`ĝ` | 加速度读数、重力读数、单位重力方向 |
| `a_v`、`a_h`、`d` | 竖向 / 横向动态加速度、动态加速度向量 |
| `sigma` | `std(\|a−g\|)`，绝对幅值量，只作静止 / 快跑门限 |
| `ptn` | v5 的峰谷归一化比，**非平移不变**（§3.3） |
| `rob_skew` | 稳健偏度 `(q95+q05−2·q50)/(q95−q05)`，对零偏与增益不变 |
| `acp`、`zcr` | 窗自相关峰、过零率，用于慢走 / 上楼打分 |
| 留一（LORO） | 留一段记录做测试、其余重标定的协议 |
| LODO | 留一天：训练另两天、测试留出天 |
