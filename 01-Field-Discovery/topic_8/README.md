## 0 摘要

同一个 8 s 窗里，用手机的加速度能不能判出「静止 / 平地慢走 / 快跑 / 上楼 / 下楼」？能，但难点不在同一天：v2/v4/v5 在同一批数据上做到 97–99 %，**换一天（同一台 PKG110）只剩 79.7 %**。v5.1 与 v6 把这个数字拉回 **94.6 % / 94.5 %**，记录级 9/9。

原因不是"特征不够多"，而是**一个特征少了一条不变性**：判下楼的 `ptn=(峰−谷)/(峰+谷)` 会随窗内残余零偏平移，而跨日漂移的正是零偏。换成对零偏与增益都不变的稳健偏度 `rob_skew`，同一个分位标定就分得开了。

| `data_2` 记录级（7 段） | 7/7 | 7/7 | 7/7 | 7/7 | 7/7 | 7/7 |

五条结论：

1. **绝对幅值类规则过不了时间漂移。** v2 在本人同一天数据上 97.4 %，同日晚间→早间掉到 73.9 %，次日只有 42.8 %；v3 换步频/比值也救不回来（45.3 %）。
2. **波形类特征救回同日跨时段。** v4 改用峰/谷检测 + 窗内自相关后，同日晚间→早间 93.1 %、跨日 68.6 %。
3. **v5 的零偏校正 + 分位标定 + 打分把同人同机推到 98–99 %，跨日仍是 79.7 %。** 差距的来源不是阈值没调好，而是 `ptn` 这个量本身不是平移不变的。
4. **v5.1 只换这一个判决量（122 → 14 个窗不再被下楼误吞），跨日 79.7 % → 94.6 %，其余口径基本持平（同日反向 -2 点，见 §4.6）；v6 把这条不变性写成可执行的自检，并用段级解码把留一推到 95.9 %。**
5. **剩下的 5.4 % 是慢走↔上楼的真重叠与切换窗**，靠加单窗特征换不来：要么补更多天/更多场景的数据，要么把输出单位从“窗口”改成“段”（记录级已经 9/9）。

## 2 方法

### 2.1 逐样本重力解耦与清洗

`g(t)` 为 Gravity 读数，`ĝ = g/|g|`：

```
a_v = a·ĝ - |g|                 竖向动态加速度（扣掉 9.8 常量）
d   = a - g                     动态加速度向量
a_h = |d - (d·ĝ)ĝ|              横向动态幅值（= √(|d|² - a_v²)）
```

静止时 `d ≈ 0`，运动时 `|d|` 就是不含重力的动态加速度。

![图2](output/v2/figures/fig2_decompose.png)

**图 2**　姿态解耦：上图的 `ax/ay/az` 随握持姿态整体旋转，下图的 `a_v`、`a_h` 才与"手机怎么拿"无关。

清洗作用在 `|a-g|` 上（含 g 的模式下 `|a|` 永远不会掉到 2 以下，v1 的掉零规则无效）：两端 0.5 s 滚动标准差 < 全段中位数的 0.3 倍时判为首尾静止段丢弃（仅当全段中位数 > 0.5 时启用）；两端 0.5 s 标准差 > 中位数的 3 倍时判为拿起/放下瞬态丢弃；两端再各留 0.5 s 保护带。清洗只处理首尾，中段的真实动作保留（如 `stand` 在 27 s 拿起手机）。

![图1](output/v2/figures/fig1_waveforms.png)

**图 1**　五类状态的纯动态加速度 `|a-g|` 波形，红底为清洗剔除的首尾段。

### 2.2 特征：先分不变性，再谈判别力

v6 把特征按**变不变**分成四类，这是全仓库的方法论主线：

| 类别 | 特征 | 对零偏 `s→s+c` | 对增益 `s→a·s` | 用途 |
|---|---|---|---|---|
| **不变核** | `rob_skew = (q95+q05−2·q50)/(q95−q05)` | 不变 | 不变 | 判下楼 |
| | `acp`：0.30–1.20 s 内自相关峰 | 不变 | 不变 | 慢走/上楼打分 |
| | `zcr`：过零率 | 不变 | 不变 | 慢走/上楼打分 |
| 协变量 | `rob_skew` 在 `s→−s` 下变号 | — | — | 符号即上/下楼的物理差别 |
| **非不变** | `sigma = std(\|a−g\|)` | — | 随增益线性变 | 只做静止/快跑两个门限 |
| 诊断量 | `cadence`、`i_cv`、`ac_lag`、`bias` | — | — | 只输出，不进判决 |

为什么较真：v5 判下楼的 `ptn=(mean(pv)−mean(tv))/(mean(pv)+mean(tv))` 看起来是"比值"，但分子分母都含 `pv+tv`，给窗内所有样本加常数 `c` 时峰抬 `c`、谷的绝对值降 `c`，`ptn` 随之改变。窗内减中位数只能压掉当天的 `c`；估偏或 `c` 随手持变，判决就漂。跨日漂的正是这个量。

早期版本的绝对幅值特征（v2/v3 的 `σ`、`p99`、`σ_v`、`f_dom`、`r`）在同集上判别力很强，但一旦换一天整体偏移就失效（§3.2、§3.3），是“先看判别力、后看不变性”的代价。

### 2.3 判决：分位标定 → 分层规则 → 段级解码

1. **分位标定**：所有阈值取两个类 2 %/98 % 分位之间的中点，不用 `max/min`——单个异常窗就能把极值阈值拖走。有符号量（`rob_skew`）用算术中点；绝对值量（`sigma`）用几何中点。
2. **分层规则**（顺序与 v4 一致）：`sigma` 低于静止门限 → 静止；高于快跑门限 → 快跑；`rob_skew` 高于下楼门限 → 下楼；`−z(acp)−z(zcr)` 高于门限 → 上楼；否则慢走。权重固定为 1，不在测试集上调。
3. **段级解码**：逐窗判决是"观测"，解码在状态图（`walk` 在中心，其余四类只在走路时进出）上最小化
   `Σ 观测代价（判对 0 / 判错 1） + Σ 切换代价（penalty × 图上距离）`。
   `penalty` 只在留一上选（v6 得 1.0），离线整段解码；因果模式（只看过去窗）也实现了。

### 2.4 窗长与步长

**8 s 窗 / 1 s 步长**。4 s 在 1.7 Hz 步频下只有约 7 步，`σ_v`/`σ_h` 的估计方差大。同一套 v2 流程在 `data_2` 上：4 s 91.8 %、6 s 94.9 %、8 s 97.4 %、10 s 99.7 %（10 s 时 `run-1` 不足一个窗被整体丢掉，只剩 6 段 288 窗，与前三档不可比，故取 8 s）。这个"加长窗就涨"的现象在跨日盲测上会反过来咬人：16 s 窗能到 99.7 %，但留一掉到 84.3 %，因为 `data_2/run-1` 只有 11.9 s，长窗下快跑整类消失（§4.7）。

### 4.6 v5.1：只换一个判决量，跨日 79.7 % → 94.6 %

**根因。** `ptn` 的分子分母都含 `pv+tv`，给窗内所有样本加常数 `c` 时峰抬 `c`、谷的绝对值降 `c`，`ptn` 随之改变——它不是平移不变的。"窗内减中位数"只是把当天的 `c` 估出来减掉。

**换成稳健偏度。** 5 %/95 % 分位：

```
rob_skew = (q95 + q05 − 2·q50) / (q95 − q05)
```

加 `c` 时三个分位各加 `c`，分子分母同时不变；乘 `a` 时分子分母同乘 `a`。即**加性零偏与增益都进不了判决**。

**阈值估计器也跟着修了一处。** 有符号量上继续用 v4 的几何中点会被 0 附近的 q98 拉到多数类一侧：只拿 10-24 标定、测 `data_2` 时，`rob_skew` 的 walk/up q98 只有 +0.001，几何中点给出 0.013 的阈值，而 `data_2` 慢走上尾是 0.062，准确率只有 83.4 %；改成 2 %/98 % 分位间隔的**算术中点**后 94.4 %。v5 的 `ptn` 仍用几何中点，历史数字保持可复现。

| 口径 | v5 | v5.1 |
|---|---|---|
| `data_2` 同集 | 98.01 % | 98.01 % |
| routine 同集 | 99.06 % | 99.06 % |
| 留一 16 段 | 95.65 % | 95.54 % |
| 留一 walk/run（4 段） | 98.41 % | 98.41 % |
| **跨日 2026-10-25** | **79.7 %** | **94.60 %** |
| 跨日 去重叠 | 78.9 % | 92.2 % |
| 跨日 记录级 | 9/9 | 9/9 |
| 跨数据集 `data_2`→routine | 94.84 % | 94.84 % |
| 跨数据集 routine→`data_2` | **96.36 %** | 94.37 % |

**代价（明确记下）**：只用 10-24 标定、测 `data_2` 的那一折，v5.1 比 v5 低 2 个点（94.4 vs 96.4）——`rob_skew` 在 `data_2` 与 10-24 之间也有约 0.07 的数据级偏移（`ptn` 只有 0.03），只是它离下楼的间隔更大；两个方向的平均 v5 95.6 % / v5.1 94.6 %。

**实现**：复用 v5 的整条流水线，只改判决量与阈值估计器（`src/v5/gait_analysis_v5.py --asym rob_skew`，默认 `ptn` 时与改造前逐位一致），所以两个版本的差异可以归因到这一处。产物在 `output/v5_1/`。

### 4.7 v6：把"不变性"写成自检 + 段级解码

**四层，一个命令跑完全部口径：**

| 文件 | 职责 |
|---|---|
| `src/v6/invariants.py` | 对 `s→s+c`、`s→a·s`、`s→a·s+c` 逐特征断言不变（RTOL 1e-9）；对 `s→−s` 断言 `rob_skew` 变号；对 `std` 断言"它确实会变"，防止有人把绝对量悄悄挪进不变核 |
| `src/v6/features.py` | 不变核 / 诊断量 / 非不变量显式分列（§2.2 的表） |
| `src/v6/model.py` | 分位标定 + 分层规则 + 段级解码（Viterbi） |
| `src/v6/evaluate.py` | 同集 / 留一 / 跨日 / 因果 / 去重叠 / bootstrap |

这个自检不是形式主义：**如果它早存在，v5 的 `ptn` 在写下的当天就会被判不合格，79.7 % 这个数字根本不会出现。**

**最终判决参数**（`data_2 + 2026-10-24` 标定，2 %/98 % 分位；完整报告见 `output/v6/report.txt`）：

| 判决 | 特征 | 阈值 |
|---|---|---|
| 静止 | `sigma` | 1.100 |
| 快跑 | `sigma` | 4.121 |
| 下楼 | `rob_skew` | +0.1108 |
| 上楼 | `−z(acp)−z(zcr)` | +0.633 |
| 其余 | — | 平地慢走 |
| 段级解码 | Viterbi | penalty = 1.0（只在留一上选） |

`sigma` 是唯一保留的绝对幅值量，只用于静止/快跑两个门限；`rob_skew` 与 `acp`/`zcr` 对零偏、增益不变（§2.2）；up score 的 z 归一化参数在标定集上固定，权重为 1。

**段级解码的消融**（`penalty` 只在留一上选）：

| 解码 | 留一（942 窗） |
|---|---|
| 不平滑 | 94.48 % |
| ±2 窗多数票（v5/v5.1 口径） | 95.54 % |
| Viterbi，penalty=0.3 | 94.48 % |
| Viterbi，penalty=0.6 | 95.12 % |
| **Viterbi，penalty=1.0（选中）** | **95.86 %** |

`penalty=1.0` 意味着"切一次"与"错一窗"等价，于是解码只抹掉孤立的单窗跳变，不会像 ±2 多数票那样把真实的两窗切换也抹平。

**为什么不换成学习模型。** 同一留一协议下，对角高斯朴素贝叶斯（`rob_skew`/`acp`/`zcr`/`log σ`）留一 87.26 %，规则 95.86 %；快跑一类就丢掉 69/157（绝对幅值的重尾被高斯假设拖垮）。16 段记录撑不起判别模型，v6 因此不引入学习层。

**v6 没有做什么（也是结论）**：

1. 没把 `sigma` 换成不变量。试过 `acp`、谱熵、8–20 Hz 能量占比、峰度做尺度无关的静止/快跑判据，静止与运动的间隔都会从“0.06 vs 2.0 m/s²”掉到 0.37 vs 0.43 这种不可用的重叠区。`sigma` 保留并标注为“换另一台设备时第一个要复查的量”。
2. 没加长窗。16 s 窗在跨日盲测上能到 99.7 %，但留一掉到 84.3 %（`data_2/run-1` 只有 11.9 s，长窗下快跑整类消失）。
3. 没做会话级归一化。单段记录只有一种状态，减段内中位数会把唯一的状态也减掉；需要"一天连续记录"的数据才成立。

## 5 讨论与局限

1. **同日跨时段与跨日不是同一难度。** v4/v5/v5.1 在同日留一批（`data_2` ↔ `2026-10-24`）上是 93.1/94.8/94.8 %（反向 97.0/96.4/94.4 %），跨日是 68.6/79.7/94.6 %。v4/v5 跨日分别掉 24.5/15.1 个点；v5.1 在两个口径上都是 94.5 % 左右，说明换成 `rob_skew` 后，跨日的主要误差源已不再是零偏漂移。
2. **5 类的瓶颈是特征重叠。** 慢走夹在上楼与下楼之间；`2026-10-24` 的 `walk-4`/`walk-5` 在 v2 只有 71.4 %/44.2 %。v5.1/v6 剩下的 38 个跨日错窗里 24 个是慢走↔上楼。
3. **留一从 4 段扩到 16 段，但仍是一人一机。** v4 的 95.8 % 只留 4 段 walk/run；v5 之后在全部 16 段上重做，v6 得 95.9 %。跨日只有一次。
4. **严谨性上的欠账。** v5.1/v6 的 94.6 %/94.5 % 都是在看到 2026-10-25 之后选定的方向上得到的，只能当回归集回看；"不变性"这个选型理由先于数字成立、也能用 `src/v6/invariants.py` 独立验证，但真正可引用的跨日数字需要另采一天。
5. **绝对加速度值不能当人体加速度读。** 快跑峰值 111 m/s² ≈ 11.3 g，来自手机在掌中拍击/翻转，只作为"区分快跑"的信号特征。
6. **静止门限的验证面很窄。** 2026-10-25 有 39 个静止窗，`stand=1.100` 判对 39/39；2026-10-24 的 38 个静止窗也全部判对；换设备时这个门限还未检验。
7. **窗口重叠放大样本量。** 8 s 窗 / 1 s 步长使 704 个窗去重叠后只剩 90 个；点准确率应结合区间读，不宜按独立样本数比较。
8. **v5.1 与 v6 只差 1 个窗。** 94.60 vs 94.46。v6 的收益在留一（95.9 vs 95.5）、同集/同日跨时段和“以后不会再出同类错”，不在跨日。
9. **在线场景需要重验。** 因果模式下 v6 93.32 %、v5.1 93.75 %，段级解码的离线收益没有带到在线。
10. **2026-10-25 不参与阈值/权重选择。** 但它是在 v5 定稿后才进仓库的，v5.1/v6 只在这一天上验证过“不变性”这一个假设；跨日数字仍需另一天复核。
11. **照片证据只覆盖早期数据。** `data/calib/data_2`、`data/legacy/data_1` 有照片/截图；`2026-10-24`、`2026-10-25` 没有。
