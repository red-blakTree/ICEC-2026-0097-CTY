## POWER.CSV 结构

```
uptime_s,event,window_s,v5_mv,i_ma,p_mw,e_mwh
```

- `uptime_s` 的 0 点是 11-08 10:53:28；墙钟 = 10:53:28 + uptime_s
- 322 行：26 条 `CAPTURE` + 296 条 `SAMPLE`（每 5 分钟一条，全程无间断）
- `v5_mv = -1` 表示没接分压电阻，电压按 5.0 V 名义值计算
- `i_ma = 45` 是固定模型值（240 MHz 空转 + AMS1117 静态电流），**不是实测电流**；`e_mwh` 到 11:22:36 为 5400 mWh，纯模型推算
- 最后两行 uptime 4 / 6 属于复位后的新会话，与 24h 主体无关
